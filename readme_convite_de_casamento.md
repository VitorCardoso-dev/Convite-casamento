# 💍 Convite de Casamento 

Landing page elegante, romântica e responsiva desenvolvida para servir como convite digital e central de informações de um casamento

## ✨ Funcionalidades

* **Hero Section:** Destaque visual marcante com a data (14 de Março de 2026), local (Fortaleza-CE) e identidade visual romântica.

* **Detalhes do Evento:** Informações essenciais sobre a cerimônia e recepção, horários, local exato (Villa Bisutti) e *Dress Code* (Traje Esporte Fino com sugestões de tons claros e terrosos).

* **Nossa História (Timeline):** Linha do tempo interativa destacando os capítulos mais importantes da trajetória do casal (desde o primeiro olhar em 2019 até o pedido em 2024).

* **Galeria de Momentos:** Exibição de fotos do casal e indicação da hashtag oficial da celebração 

* **RSVP (Confirmação de Presença):** Módulo interativo para que os convidados confirmem presença, registrem acompanhantes e interajam com os noivos.

* **Atendimento via WhatsApp:** Botão flutuante integrado para facilitar o contato e esclarecimento de dúvidas dos convidados.

## 🚀 Tecnologias Utilizadas

* **HTML5** (Estrutura semântica e acessível)

* **CSS3** (Estilização personalizada, Flexbox, Grid e layout totalmente responsivo para celulares e desktops)

* **JavaScript (Vanilla)** (Lógica para interatividade, navegação suave e formulários)

* **Google Fonts** (Tipografia refinada)

## 📂 Estrutura do Repositório

```
├── index.html       # Estrutura principal da página (Hero, Evento, História, Galeria, RSVP)
├── style.css        # Folha de estilos e design responsivo
└── script.js        # Scripts de interatividade e comportamento da página

```

## 💻 Como Executar Localmente

Por ser uma página web estática, você não precisa configurar servidores ou ambientes complexos:

1. Faça o download ou clone este repositório.

2. Abra a pasta do projeto no seu editor de código preferido (como o VS Code).

3. Abra o arquivo `index.html` diretamente no seu navegador ou utilize a extensão **Live Server** para visualizar as alterações em tempo real.
